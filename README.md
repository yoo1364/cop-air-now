# 지금, 우리 동네 공기

에어코리아(한국환경공단) 시도별 실시간 측정정보 API로 전국 측정소의 PM2.5·PM10을 받아
한 화면에 보여 주는 대시보드입니다. Python 3 표준 라이브러리만 쓰므로 따로 설치할 것이 없습니다.

## 준비

이 폴더의 `.env` 파일에 공공데이터포털 인증키를 넣어 둡니다(이 파일은 `.gitignore`로 제외됩니다).

```
DATA_GO_KR_KEY=발급받은_인증키
```

## 수집과 실행

```bash
python3 fetch_air.py                           # air.json 생성
python3 -m http.server 8000 --bind 127.0.0.1   # 로컬 서버 실행
```

브라우저에서 http://localhost:8000 을 엽니다. `index.html`은 `air.json`을 fetch하므로
파일을 직접 더블클릭하지 말고 서버로 열어야 합니다. 최신 값이 필요하면 `fetch_air.py`를 다시 실행하고 새로고침합니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `fetch_air.py` | 1건으로 응답 구조를 확인한 뒤 전국 자료를 받아 `air.json` 저장. 오류(HTTP 403 포함)는 한국어로 안내하고 종료하며, 실패하면 기존 `air.json`은 그대로 둡니다. |
| `air.json` | `source`, `fetchedAt`, `dataTime`, `stations[]`(`sido`, `station`, `pm10`, `pm25`, `khaiGrade`). `-`·빈 값은 `null`. |
| `index.html` | 요약 카드, 시도별 평균 PM2.5 막대그래프, 측정소 검색·표. 외부 라이브러리 없음. |

`air.json`에 `"sample": true`가 있으면 화면에 ‘샘플 데이터(가상 값)’ 배지가 표시됩니다.

## PM2.5 등급(㎍/㎥, 평균은 반올림해 판정)

좋음 0–15 · 보통 16–35 · 나쁨 36–75 · 매우나쁨 76 이상. 값이 없는 측정소는 ‘점검 중’으로 표시하고 평균에서 제외합니다.
